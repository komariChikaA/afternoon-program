# 实现决定与需求映射

## 当前项目状态

任务：制作《下午的节目》第一版完整可玩原型。仓库根目录的 `.git` 是空目录，`git status` / `git remote -v` 均报告非 Git 仓库；没有可识别的远端，所以无法创建 Issue、分支、PR 或推送。仅创建独立 `afternoon_program/`，保留既有 cake、剧本项目和共享模板。

当前需求与进度保存在本文件和验证记录中，便于以后导入 Issue。完成 Agent 技术验证后属于 Qualified，仍待玩家对节奏、恐怖感与占位美术进行验收，不自行宣布 Ranked。

## 引擎边界

检查过自带 SKILL.md、data-contracts、editor-and-engine、模板 README/package.json、三个引擎模块、场景与时间轴数据、可视编辑器和 cake 示例。

已有能力：经典脚本桥、背景/单角色/对白层、打字、基础动画、click/Space/Enter、goToScene、时间轴 seek/play、contain、自带三层编辑器。

缺少能力：真实分支、持久变量、存档、标题、声音；`hotspots` 仅存在数据字段，renderer 没有实际实现热点。选择以传统 VN 的按钮完成移动/调查，不另造地图引擎。

三个 engine 文件不修改。游戏层调用原 `VNPlayer.goToScene()`，让原 renderer 建立场景，再添加电视层和选择。覆盖 `VNPlayer.next` 使其按节点图走；覆盖 VNAnimation.typeInteractive 的可取消计时器以实现补全文字，避免每次推进遗留定时器。项目特效参数写在数据，图层与音频播放器不硬编码故事台词。

## 双循环与 12 处差异

1. 合照五名大人变四名；人物排列空出一块。
2. 门边四双拖鞋变两双；底上没有第一轮的痕迹。
3. 林爷爷没有进门、左侧实景座位空着，电视里仍有人。
4. “下午他们要来”变“下午他们还要来”；次日“会来”变“还会来”。
5. 灰蓝外套提前挂着，属于林爷爷的袖口白线重复。
6. 电视无操作短暂亮起。
7. 尚未到场的人提前在电视左侧出现。
8. 照片人脸被铅笔线覆盖，玻璃仍光滑。
9. 电视逐步经历 lowres / still / outline / drawing / cartoon。
10. 男式衬衣、裤子、围巾出现在未对应到场人员的位置。
11. 母亲消息、锅里的粥、椅子对白、番茄面等原句重复。
12. 舅公提前说“把杯子放干净的地方”“钥匙放门边，路上小心”。

额外克制细节：名单五行变三行，蜡笔牙印消失，字幕短暂“留下的人”，镜头盖未摘，麦子腹部细缝与幼小前脚的形状呼应。当前 HUD 只显示地点和时间，不写周目编号，RESET 不给解释。

## 剧情图

按章节顺序串联。day1-observe → TV/照片/麦子 → day1-observe；完成调查或直接选厨房继续。day2-walk → 外套/名单 → day2-walk。loop2-observe → 重复场景调查 → loop2-observe。pet-intervene 必须选择“拉住它” → fear-understanding。home-actions → 锁门/窗帘/洗脸 → home-actions → 上床。调查改变少量布尔变量和末尾细节，没有救宠物或解释真相的隐藏结局。

调查不是主线门槛。最终回家可以直接休息，也可以逐项操作。主角“拉住它”的主动行为是唯一强制选择，保证恐惧出现的时机不会被跳过。

## 视觉与音频节奏

日常使用低饱和实景照片；血迹为保留木纹的深红栅格合成，衣物与机壳均来自公开照片。TV 六种画面保持 640×440，使用约 60～70 岁外观的越南彩色正面人像，取代历史名人及欧美老人。真实年龄未有来源记载，详见素材说明。

AFTERNOON A/B 使用低底噪，第一轮无心跳和恐惧 UI。第二轮 afternoon-b-013 的电视变化、afternoon-b-031 的宠物事件和 clothes-1 的衣物落下各有一次短促 jumpscare：短黑场、摄影近景、冲击音同步出现。节点等待覆盖演出时长；恢复存档不重播惊吓，退出到标题取消延迟。用户可关闭突发惊吓，减少动态同时禁用其画面与音效。

只有 escape 的 fear-understanding 起启用极轻 UI 漂移、深暗角、呼吸感与心跳；公交站衰减，家中恢复普通环境，睡前静音。白天播放低音量萨蒂录音。ending 先留 1.8 秒黑场，再以七张真实衣物合成 CG、布料声和压力环境音累积，最后停留后回到静音。

不制作追逐、密码谜题、战斗或真相解释。公开素材与程序素材全部本地化；没有依赖在线字体、CDN 或外部声音服务。

## 后续人工评审项

本版已经是完整可玩故事。实景、美术合成和真实人像已替换主要占位画面，独立角色立绘及环境音仍有原型性质；没有配音。静态照片合成还存在轮廓、光线及墙面修补痕迹。不把图像解码、自动浏览器通关等技术检查当成人类视觉、听觉或恐怖节奏验收。30～60 分钟成品范围需要后续内容和演出扩充，避免用强制等待充时长。

## 阅读控制与编辑更新

Ctrl 按住与已读快进按钮只跳过浏览器记录过的节点，遇到未读或选择停止；Auto 等待打字与节点演出完成后推进，在菜单、选择和失焦时暂停。存档保留当前位置与分支状态。

v0.3 对正文进行 88 处措辞修订，并将家具描述匹配实际摄影场景，保留剧情图、亲戚与宠物命运和结局的不解释。编辑器解析背景及角色地址时以项目根目录为基准，避免 /editor/assets/ 错误路径。
